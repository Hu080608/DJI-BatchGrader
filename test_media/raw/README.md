# RAW test sample

`sample_blackmagic.dng` is a CC0/public-domain sample downloaded from
[raw.pixls.us](https://raw.pixls.us/) (Blackmagic Micro Cinema Camera, 12-bit DNG).

Source file page:
https://raw.pixls.us/getfile.php/7316/nice/Blackmagic%20-%20Micro%20Cinema%20Camera%20-%2012bit%20%2816:9%29.dng

It is used only by the local RAW acceptance test and is not included in the
Windows release ZIP.
