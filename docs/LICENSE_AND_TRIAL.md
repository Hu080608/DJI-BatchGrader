# 授权与试用说明

本软件采用**离线买断制商业授权**，不要求注册账号，不依赖在线授权服务器。

## 一、下载即用

软件可以从 GitHub Releases 免费下载。首次启动会**自动开始 7 天免费试用**，无需注册、无需授权文件。

试用期间：

- 核心功能全部可用；
- 输出不加水印；
- 授权状态绑定当前机器码；
- 不要求联网。

## 二、试用结束

7 天试用到期后，软件停止新建批处理任务，但不会删除：

- 已生成的素材；
- 配置和 LUT；
- 日志和报告。

如需继续使用，请联系作者购买买断授权。

## 三、购买和导入买断授权

1. 启动主程序，打开“授权信息”窗口。
2. 点击“复制机器码”。
3. 添加作者 QQ：**3643791089**。
4. 提供机器码并购买买断授权。
5. 收到作者签发的 `license.json` 后，点击“导入许可证”。

授权文件使用 Ed25519 数字签名，必须与当前机器码匹配。

## 四、买断授权

- 买断授权不设到期日。
- 授权绑定当前设备，可在同一设备上长期使用。
- 换机、重装系统或硬件变化导致机器码变化时，请联系作者重新签发。
- 更新软件不会使仍然有效的买断授权失效。

## 五、机器码与隐私

机器码由 Windows 设备信息哈希得到，不包含原始硬件编号或个人信息。素材全程本地处理，不上传。

## 六、边界

离线授权无法像在线账号那样即时吊销或远程停用。作者可以在新版本中内置已泄露授权的停用名单，但旧版本无法远程失效。试用状态可以绑定机器码并加密保存，但无法阻止重装系统、更换 Windows 用户或使用虚拟机重新开始试用。购买、退款和授权范围以正式订单或合同为准。
