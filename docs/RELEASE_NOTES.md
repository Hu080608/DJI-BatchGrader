## 处理范围

- 导入区域新增三选一处理范围：
  - 只处理视频
  - 处理视频 + RAW
  - 全部处理（默认）
- 选择“只处理视频”或“处理视频 + RAW”时，普通 JPG/PNG/TIFF/HEIC 照片会被跳过，不报错、不中断。
- 日志、任务摘要和完成提示会显示“跳过范围”的数量。
- 文件夹监听、拖拽导入和批处理发现逻辑均使用同一范围规则。

## RAW 照片支持

- 新增 rawpy/libraw RAW 解码，支持 DNG、CR2、CR3、NEF、NRW、ARW、SRF、SR2、RAF、RW2、ORF、PEF、SRW、3FR、FFF、IIQ、KDC、MEF、MOS、MRW、X3F 等常见扩展名。
- 使用相机记录的 White Balance；缺失时回退 LibRaw 自动白平衡。
- 输出色彩空间为 sRGB，LUT 在 float32 中分块应用。
- RAW 输出为 16-bit RGB TIFF，命名规则为 `<原文件名>_graded.tif`。
- 解码失败、损坏或不受 LibRaw 支持的文件按单个任务失败处理，不影响其他文件。
- 新增 rawpy 0.27.1 和 tifffile 依赖。

## 视频处理优化

- 视频 LUT 插值默认改为 tetrahedral（四面体插值），在保持/改善色彩插值质量的同时降低 CPU 开销。
- 当 LUT 使用 CPU `lut3d` 滤镜时，默认改用软件解码，避免 GPU 解码后再下载到 CPU 的显存往返；NVENC/QSV/AMF 编码仍优先启用。
- 同一 4K 测试素材实测中位总耗时从约 14.24 秒降至约 11.24 秒，提升约 21.1%。

| 项目 | 优化前 | 优化后 |
|---|---:|---:|
| 4K 8 秒 30fps 视频总耗时 | 14.24 s | 11.24 s |
| 等效处理帧率 | 16.85 fps | 21.35 fps |
| 输出编码 | H.264 NVENC | H.264 NVENC |

测试环境：Intel Core i9-14900HX、32 GB RAM、NVIDIA GeForce RTX 5080 Laptop GPU 16 GB、FFmpeg 6.1.1。

## 兼容性

- 原有 JPG/PNG/TIFF/HEIC、视频格式、输出格式、LUT 和报告字段保持兼容。
- 默认处理范围仍为“全部处理”。
- 视频 LUT 插值默认从 trilinear 改为 tetrahedral；如需旧行为，可在 `config/settings.json` 设置 `"video_lut_interp": "trilinear"`。
- 软件解码默认用于 CPU LUT 路径，输出格式不变；视频编码仍优先使用硬件编码器。
